# What's changed

This page lists the changes to the District 26 Green Infrastructure Web Map that a reader would notice: new map layers, new text, fixes, and corrections when we published something wrong. Newest first. BetaNYC's Civic Innovation Lab built the map for the Office of Council Member Julie Won. Routine data refreshes are not listed.

- **History begins:** 2026-06-23, the day the map went online. Every change since then is listed.
- **Data refresh:** flood-related 311 service requests daily, from NYC Open Data; the other City and federal sources weekly, on Mondays.

To report a bug in this map or ask for a new feature, [open an issue on GitHub](https://github.com/BetaNYC/d26-gi-web-map/issues).

## 2026-11-12: A What's changed page

- **Tags:** Site
- **What changed:** A new page lists every change to the map a reader would notice, newest first, with a filter for site changes and data changes. The map links to it at the bottom.
- **More detail:** [What's changed on GitHub](WHATS-CHANGED.md)

## 2026-07-17: Hotspots of flood-related 311 requests

- **Tags:** Data, Site
- **What changed:** A new map layer shows where flood-related 311 service requests cluster, as a shaded surface. It can be turned on from the layer control.
- **More detail:** [Pull request](https://github.com/BetaNYC/d26-gi-web-map/pull/16) · [How the hotspots are computed](https://github.com/BetaNYC/d26-gi-web-map/pull/13)

## 2026-07-15: All green infrastructure, not only flood-related

- **Tags:** Data, Site
- **What changed:** A new toggle shows every green infrastructure asset in the area. Before, the map showed only the flood-related assets the Council Member's office asked for, and it still does by default.
- **More detail:** [Pull request](https://github.com/BetaNYC/d26-gi-web-map/pull/14)

## 2026-06-25: Fuller explanations, and fixes for phones

- **Tags:** Site
- **What changed:** The sidebar now explains the district and zip code views, the layers panel explains each layer, and the About box was rewritten. On phones, the map can pan farther and the side panel's spacing was fixed.
- **More detail:** [Text](https://github.com/BetaNYC/d26-gi-web-map/pull/2) · [Phone fixes](https://github.com/BetaNYC/d26-gi-web-map/pull/4) · [Map bounds](https://github.com/BetaNYC/d26-gi-web-map/pull/9)

## 2026-06-23: The map goes online

- **Tags:** Site, Data
- **What changed:** An interactive map of flood risk, green infrastructure, tree canopy, permeable surfaces and flood-related 311 requests in and around Council District 26, at d26-gi.beta.nyc. The sidebar compares the district with the zip codes that overlap it.
- **More detail:** [The map](https://d26-gi.beta.nyc/) · [Pull request](https://github.com/BetaNYC/d26-gi-web-map/pull/1)
